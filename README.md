# Монитор цен Основит — Петрович и Лемана ПРО

Цены конкурентов в DIY-сетях из легальных источников и сравнение с Основит за кг/л:

- **товарный фид сети** (Admitad «Товары» / «Каталог товаров», «Где Слон?», YML/CSV/Google Merchant) — основной путь;
- **окно Edge «как посетитель»** — запасной, только для того, чего нет в фиде: по списку, с паузами,
  по правилам robots.txt; проверку браузера проходит человек.

Версия — в заголовке окна; что менялось — [CHANGELOG.md](CHANGELOG.md).

## Установка

Python ставить не нужно — он вложен в сборку. На странице **Releases**:

- `Osnovit-DIY-<версия>-Setup.exe` — установщик: без прав администратора, в папку пользователя, ярлыки в «Пуске»;
  обновление — запустить установщик новой версии (данные остаются), удаление снимает задачи Планировщика;
- `Osnovit-DIY-<версия>-Windows.zip` — то же архивом: распаковать (не в Program Files) и запустить `Запустить.cmd`;
- `Osnovit-DIY-<версия>.zip` — без Python, если Python 3.10+ уже есть.

Подробно, в том числе для ИТ (что и куда ставится, сеть, тихая установка, перенос данных) — [docs/install.md](docs/install.md).

**Обновление архивом** с 2.1 и новее: замените всё, кроме папки `data`. База обновится сама (миграции),
настройки сохранятся.

## Первый запуск

1. **Фид.** В Admitad или «Где Слон?» добавьте площадку и подключитесь к программам Лемана ПРО и Петрович.
   После одобрения вставьте ссылку на фид в «Настройки → Ссылка на фид» и укажите город цен фида.
2. **«Проверить связь»** — приложение скачает фид и покажет, сколько в нём позиций и категорий.
3. **«Что отслеживаем»** — выберите категории фида; отдельные товары и разделы сайта — ссылками.
4. Для запасного пути: «Настройки → Открыть сайт в окне сбора», выберите в окне город.
5. **«Собрать цены»** на Главной. Отчёт Excel — в `Документы\Монитор Основит DIY`.
6. **«Сбор по расписанию»** в Настройках: каждый день в заданное время и проверка «сбор прошёл?» каждые 6 часов
   с уведомлением Windows (и, если задан, webhook — например, Telegram-бот). Пропущенный сбор пройдёт сразу после
   включения компьютера.
7. **«Проверить компьютер»** в Настройках — всё ли есть для сбора по расписанию.
8. **Пилот:** вкладка «Проверка» → «Новая выборка» → сверьте 30 карточек с сайтами. Ошибки фасовки и вида
   исправляйте там же. Точность видна на Главной и в отчёте; цель — 90 % и выше.

## Автопоиск аналогов

После сбора приложение просматривает весь фид сети: находит все товары Основит (даже вне отслеживаемых категорий)
и аналоги конкурентов тех же видов — штукатурки, затирки, шпаклёвки, клеи, наливные полы… с понятной фасовкой.
Они попадают в сравнение и в отчёт с пометкой «автопоиск». Выключается в Настройках.

## Поиск аналогов по названиям

Запросы составляются из товаров Основит («Штукатурка гипсовая 30 кг»), каждый сбор — несколько по кругу, поиском
на сайте сети в окне Edge (если robots.txt разрешает). Берутся товары того же вида с понятной фасовкой. Для каждого
запроса есть «Найти в Яндексе» — во вкладке «Что отслеживаем».

## Сбор с сайта: «полка → карточки»

0. **Разделы листаются до конца:** «Дальше», номера страниц, «Показать ещё»; прокрутка и ожидание товаров.
1. **Окно готовит человек** (сбор из окна приложения): окно Edge открывается на экране — выберите город, если надо,
   пройдите проверку и нажмите «Готово» на Главной. Город запоминается для сборов по расписанию.
2. **Shallow:** страницы разделов с пагинацией — название, цена, ссылка, наличие, город.
3. **Матчинг с фидом:** по артикулу, иначе по названию и фасовке.
4. **Deep — только по делу:** не понять фасовку; цена «от …»; цена расходится с фидом больше 10 %; не распознан
   вид товара, нужный для аналогов. Цена совпала — карточку не открываем. Лимит страниц и паузы — общие.

## Вкладки

| Вкладка | Что там |
|---|---|
| Главная | кнопка сбора; итог; Основит против аналогов (самые дорогие и дешёвые); изменения; «На проверку» |
| Товары | поиск по всем товарам; карточка: вид товара, фасовка, график, аналоги, сверка, «Не конкурент» |
| Проверка | выборочная проверка 30 карточек, точность, исправление фасовки и вида |
| Что отслеживаем | категории фида, ссылки на разделы и товары, ваши решения |
| Настройки | фид и окно сбора по каждой сети, вторая папка для копий, расписание, проверка компьютера |
| Состояние | *режим специалиста:* здоровье, источники на паузе, метрики, дампы сбоев, копии, журнал |

**Режим специалиста** (Настройки → Общее) показывает вкладку «Состояние», «Откуда цены» на Главной и тонкие
настройки: паузы, лимиты страниц, путь к Edge, сверку с сайтом, снимки при сбоях, webhook.

## Надёжность

- **429 и капча** — источник сразу встаёт на паузу не меньше чем на час (или на `Retry-After`), при повторах
  2 ч, 4 ч… до 24 ч. Капчу приложение не решает и не обходит.
- **Повторы с нарастающей паузой** для фида (5 → 20 с) и страниц (12 с); **предохранитель**: три сбоя подряд —
  пауза источника; удачный сбор её снимает. Снять вручную — «Состояние → Снять паузу».
- **Дампы при сбоях**: HTML страницы, снимок экрана и описание — в `data\failures` (не больше 60 / 200 МБ).
- **Журнал** в JSON с уровнями и контекстом (номер сбора, сеть, адрес) — `data\logs\monitor.jsonl`, ротация.
- **Метрики** каждого источника: время, запросы, ошибки, повторы, 429, капчи, пустые замеры, цены.
- **Транзакции**: цены сети пишутся одной транзакцией; история не задваивается; один сбор за раз.
- **Резервные копии** базы и настроек после удачного сбора: 10 последних и по одной за 8 недель; по желанию —
  ещё и во вторую папку (сетевой диск, облако).
- **Здоровье и dead man's switch**: если сбора не было дольше 26 ч — уведомление.

## Командная строка

```
Запустить.cmd                 окно приложения
Запустить.cmd --run           сбор без окна (так его запускает Планировщик)
Запустить.cmd --watchdog      проверка «сбор прошёл?» с уведомлением
Запустить.cmd --health        здоровье в JSON; код выхода 0 — в порядке, 1 — предупреждения, 2 — плохо
Запустить.cmd --backup        резервная копия сейчас
Запустить.cmd --restore ФАЙЛ  восстановить базу из копии (приложение закрыто)
Запустить.cmd --selftest      проверка компьютера: Python, Edge, папки, Планировщик, уведомления, сеть
Запустить.cmd --unschedule    снять задачи Планировщика (так делает удаление программы)
```

## Разработка

Только стандартная библиотека Python 3.10+ (приложение работает на переносном Python).

```
pip install ruff mypy
ruff check . && ruff format --check . && mypy      # стиль, ошибки, типы
python -m unittest discover -s tests                # офлайн-тесты; тест окна — если найден браузер
python tools/build.py                               # dist/Osnovit-DIY-<версия>.zip
```

Сборки для Windows (ZIP с Python и установщик) — см. [docs/install.md](docs/install.md#сборка-для-разработчика).

CI (`.github/workflows/ci.yml`) на каждый коммит: ruff и mypy; тесты на Ubuntu и Windows под Python 3.10 и 3.12;
окно сбора в Chrome (Ubuntu) и Edge (Windows, пока экспериментально) на поддельном сайте; сборка ZIP с Python
и установщика на Windows с проверкой «как у пользователя». Тег `v<версия>` — выпуск на GitHub со всеми файлами.

Образцы в `tests\fixtures` синтетические, цены вымышленные.
