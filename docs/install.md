# Установка — для пользователей и ИТ

Python ставить не нужно: в обе сборки для Windows он уже вложен (официальный «Windows embeddable package»
с python.org, версия закреплена, подпись Python Software Foundation проверяется при сборке). Скачать — на
странице **Releases** репозитория:

| Файл | Что это | Когда брать |
|---|---|---|
| `Osnovit-DIY-<версия>-Setup.exe` | установщик | обычный случай |
| `Osnovit-DIY-<версия>-Windows.zip` | та же программа архивом: распаковал и запустил | установщики запрещены политикой, флешка |
| `Osnovit-DIY-<версия>.zip` | без Python | Python 3.10+ на компьютере уже есть |
| `SHA256SUMS.txt` | контрольные суммы | сверить, что файл скачан целым: `Get-FileHash файл` |

Каждая сборка перед выпуском проверяется на чистой Windows так, как ей пользуется человек: распаковка ZIP,
установка в папку с кириллицей и пробелами, проверка компьютера, сбор цен с отчётом Excel, резервная копия,
обновление поверх запущенной программы, включение расписания и удаление.

## Требования

- Windows 10 или 11, 64-битная; около 100 МБ на диске плюс данные (обычно десятки МБ).
- Права администратора **не нужны**.
- Microsoft Edge — только для окна сбора с сайтов (он есть в Windows); для фидов не нужен.

## Установщик

1. Запустите `Osnovit-DIY-<версия>-Setup.exe`.
2. Если Windows покажет «Система Windows защитила ваш компьютер» (SmartScreen) — нажмите **«Подробнее» →
   «Выполнить в любом случае»**. Так бывает с программами без купленного сертификата подписи кода; если
   сертификат задан в настройках сборки, установщик подписан и окна нет.
3. Ставится в `%LOCALAPPDATA%\Programs\Монитор Основит DIY` — в папку пользователя, поэтому без прав
   администратора. Ярлыки — в меню «Пуск» (программа и «проверка компьютера») и, по желанию, на рабочем столе.

В Program Files установщик ставить не даст: программа хранит данные рядом с собой (папка `data`), а туда
у обычного пользователя нет прав на запись.

**Обновление** — запустить установщик новой версии. Он сам закроет программу, если она открыта или идёт сбор
по расписанию, заменит код и Python и **не тронет папку `data`**: цены, история, настройки, расписание
остаются. База обновляется сама при первом запуске.

**Удаление** — «Параметры → Приложения» или «Пуск → Монитор Основит DIY → Удалить». Удаление закрывает
программу, снимает задачи Планировщика и спрашивает, удалить ли собранные данные (по умолчанию — **нет**,
они остаются в `data` и подхватятся при новой установке). При тихом удалении данные остаются всегда.

### Тихая установка (ИТ)

```
Osnovit-DIY-<версия>-Setup.exe /VERYSILENT /SUPPRESSMSGBOXES /NORESTART [/DIR="D:\Монитор Основит DIY"] [/LOG=setup.log]
"%LOCALAPPDATA%\Programs\Монитор Основит DIY\unins000.exe" /VERYSILENT /SUPPRESSMSGBOXES /NORESTART
```

Установка идёт от имени пользователя, которому нужна программа (не от SYSTEM): и файлы, и задачи
Планировщика — его.

## Архив с Python (без установки)

1. Перед распаковкой: правой кнопкой по архиву → **Свойства → «Разблокировать»** → ОК. Иначе Windows помечает
   каждый распакованный файл как «из интернета» и спрашивает подтверждение при запуске.
2. Распакуйте в папку, где у вас есть право записи (не в Program Files): например, `Документы` или флешку.
   Если встроенная распаковка Windows исказила русские имена файлов — распакуйте 7-Zip.
3. Запустите `Запустить.cmd`. Ярлык можно сделать самому (правой кнопкой → «Отправить → Рабочий стол»).

**Обновление архивом:** распакуйте новую версию в новую папку и перенесите туда папку `data` из старой —
или замените в старой папке всё, кроме `data`. Перед переносом включённое расписание лучше выключить
(Настройки → Расписание) и включить уже в новой папке: задача Планировщика помнит путь к программе.

## Данные

Всё, что программа собрала и настроила, — в одной папке `data` рядом с программой: база, настройки, отчёты
(если папка отчётов не задана другой), резервные копии, журнал, профиль окна сбора. Перенос на другой
компьютер — скопировать `data` в новую установку (программа на обоих компьютерах закрыта). Резервная копия
базы и настроек делается сама после удачного сбора (`data\backups`) и вручную — `Запустить.cmd --backup`;
восстановление — `Запустить.cmd --restore ФАЙЛ` при закрытой программе.

## Для ИТ: что программа делает в системе

- **Файлы:** только папка программы (с `data` внутри). Реестр — только запись об установке для «Приложений»
  (если ставили установщиком). Служб и драйверов нет.
- **Процессы:** `python.exe` из папки программы; окно приложения — страница в браузере на `127.0.0.1`
  (порт выбирается свободный, вход по одноразовому ключу; снаружи компьютера недоступно). Для сбора с сайтов —
  Microsoft Edge с отдельным профилем в `data\browser`.
- **Планировщик заданий** (если пользователь включил расписание): две задачи текущего пользователя —
  «Монитор Основит — Петрович и Лемана ПРО» (сбор) и «… — проверка» (раз в 6 ч: прошёл ли сбор). Удаление
  программы снимает обе; вручную — `Запустить.cmd --unschedule`.
- **Сеть — только исходящий HTTPS:** адреса фидов, которые пользователь задал в настройках (например,
  `export.admitad.com`), и сайты сетей `petrovich.ru`, `lemanapro.ru` — для окна сбора. Обращения к python.org и
  куда-либо ещё при работе нет. Системный прокси Windows используется сам; сертификаты — из хранилища Windows.
- **Антивирус:** если корпоративный антивирус блокирует `python.exe` в папке пользователя, добавьте папку
  программы в исключения или разрешите файлы, подписанные Python Software Foundation.

## Проверка после установки

«Пуск → Монитор Основит DIY — проверка компьютера» (или `Запустить.cmd --selftest`): Python, папки и место,
база, Edge, Планировщик, уведомления, прокси и доступность фидов и сайтов — по каждому пункту «в порядке» или
что сделать.

## Сборка (для разработчика)

Сборки делает CI (`.github/workflows/ci.yml`, задача `package`) на каждый коммит. Выпуск — по тегу
`v<версия>` (тег должен совпадать с версией программы) или кнопкой: Actions → CI → Run workflow на `main` —
тег ставится сам, если все проверки прошли:

```
python tools/fetch_python.py build/python                         # переносной Python, подпись и модули
python tools/build.py --python build/python --stage build/stage   # ZIP с Python и папка для установщика
iscc /DAppVersion=<версия> /DSourceDir=%CD%\build\stage /DOutputDir=%CD%\dist installer\setup.iss
python tools/check_dist.py zip dist\Osnovit-DIY-<версия>-Windows.zip
python tools/check_dist.py installer dist\Osnovit-DIY-<версия>-Setup.exe
```

Подпись кода включается сама, если в секретах репозитория заданы `SIGN_PFX` (сертификат PFX в base64) и
`SIGN_PASSWORD`: подписываются установщик и программа удаления.
