# Как устроено и как добавить источник

## Путь данных

```
                ┌───────────── фид сети (Admitad / «Где Слон?» / файл) ─────────────┐
 tracked ──►  collect ── feeds.fetch → feeds.read ──┐                              │
 (что          │                                    ├─► found{key: товар} ─► _write ─► products, history,
 отслеживаем)  └── visitor (Edge, только пробелы) ──┘        (одна транзакция)        site_reads, crosscheck
                     cdp → extract                                                  │
                                                     analysis (аналоги, «На проверку») ─► market_points
                                                     report (Excel)  ·  metrics  ·  log  ·  backup
```

| Модуль | За что отвечает |
|---|---|
| `sites.py` | сети: домены, вид ссылок, артикул из адреса, город из адреса |
| `feeds.py` | скачать фид (повторы, 429 → пауза, 304), прочитать YML / CSV / Google Merchant потоком |
| `cdp.py` | окно Edge по протоколу DevTools (свой WebSocket на стандартной библиотеке) |
| `visitor.py` | сбор «как посетитель»: robots.txt, паузы, лимиты, проверка браузера → человек, дампы |
| `extract.py` | товары со страницы: данные страницы → schema.org → состояние в скриптах → вёрстка |
| `collect.py` | один сбор целиком: блокировка, предохранители, метрики, запись, анализ, отчёт, бэкап |
| `kinds.py`, `units.py`, `analysis.py` | вид товара, фасовка, сравнение с аналогами, правила «На проверку» |
| `spot.py` | выборочная проверка: выборка, отметки, точность |
| `schedule.py`, `selftest.py` | задачи Планировщика из XML; проверка компьютера |
| `guard.py` | повторы с нарастающей паузой и предохранитель источника |
| `log.py`, `metrics.py`, `dumps.py`, `health.py`, `backup.py` | журнал, метрики, дампы сбоев, здоровье, копии |
| `db.py` | схема, миграции, транзакции, блокировка — см. [database.md](database.md) |
| `server.py`, `ui/index.html` | окно приложения (локальная страница в Edge `--app`) |
| `report.py`, `xlsx.py` | отчёт Excel со своим писателем .xlsx и графиками |

Только стандартная библиотека Python 3.10+: приложение работает на переносном Python без установки пакетов.

## Добавить сеть (например, «ВсеИнструменты»)

1. **Сначала — легальный путь.** Есть ли у сети товарный фид в партнёрской сети? Что разрешают правила сайта
   и robots.txt? См. «Юридическая проверка» в проекте. Без фида сеть можно вести только через окно Edge — по
   отдельным разделам и карточкам.

2. **`monitor/sites.py`** — запись в `SITES`:
   ```python
   "vseinstrumenti": {
       "title": "ВсеИнструменты",
       "domains": ("vseinstrumenti.ru",),
       "home": "https://www.vseinstrumenti.ru/",
       "data_hosts": ("vseinstrumenti.ru",),   # откуда страница сама берёт данные (XHR/fetch)
       "subdomain_city": {},                   # если город задаётся поддоменом — как у Петровича
   },
   ```
   и правила в `code_from_url` (артикул из адреса карточки) и `is_section_url` (что считать разделом).
   Ключ товара `сеть:артикул` должен совпадать у фида и у сайта — иначе цены задвоятся.

3. **`monitor/config.py`** — блок сети в `DEFAULTS["sites"]` (`enabled`, `feed`, `feed_city`, `edge_enabled`,
   `edge_city`). Интерфейс и сбор подхватят сеть сами.

4. **Фид.** Форматы YML / CSV / Google Merchant уже читаются. Если колонки CSV называются иначе — добавить
   названия в `feeds._CSV_COLUMNS`. Партнёрские ссылки разворачиваются по параметрам `ulp`, `url`, `to`… —
   при новом формате дополнить `sites._WRAP_PARAMS`.

5. **Страницы сайта.** `extract.py` ищет товары по смыслу (объект, где рядом название, цена и артикул/ссылка),
   поэтому чаще всего ничего менять не нужно. Если сайт показывает «цену по карте» под другим именем — добавить
   его в `extract._CARD_HINT`, чтобы она не попала в цену на полке. Город в шапке — `PAGE_SCRIPT` (`citySel`).

6. **Тесты.**
   - фрагмент фида → `tests/fixtures/`, тест на `feeds.read` (цена, старая цена, наличие, ссылка, артикул);
   - типичные названия сети → `tests/fixtures/names.tsv` (название, ожидаемый вид, фасовка): тест `NamesCorpus`
     сразу покажет, какие названия разбираются не так;
   - сохранённая страница (из `data/failures` или `data/samples`, без личных данных) → тест на
     `extract.products_from_page`;
   - маршрут в `tests/fakesite.py` и сценарий в `tests/test_browser.py`, если у сайта своё поведение.

7. **Проверка.** `ruff check . && ruff format --check . && mypy && python -m unittest discover -s tests`,
   затем «Проверить связь» в Настройках на живом сайте и один сбор вручную. Вкладка «Состояние» покажет, каким
   путём прочитаны цены и были ли пустые страницы.

Предохранитель, метрики, журнал, дампы и транзакции работают для новой сети без дополнительного кода.

## Правила, которые нельзя ослаблять

- Только то, что в «Что отслеживаем»; robots.txt соблюдается; пауза между страницами не меньше 5 секунд.
- Никакого распознавания капчи, прокси, подмены браузера, перехваченных ключей мобильных приложений.
- 429 и капча — пауза источника не меньше часа (`guard.BLOCK_PAUSE`), а не повтор.
- Цены разных городов не смешиваются.
